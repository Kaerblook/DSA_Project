# Expense Tracker

## Setup

Install Python, then clone or download this repository from GitHub and open a terminal in the project folder (the folder containing `requirements.txt`).

Install the project's required libraries with:

```bash
python -m pip install -r requirements.txt
```

On Windows, if `python` is not recognized, use:

```powershell
py -m pip install -r requirements.txt
```

## Run the app

From the project folder, run:

```bash
streamlit run Home.py
```
